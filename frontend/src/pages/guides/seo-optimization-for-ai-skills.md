Discoverability is critical to monetizing your AI skills on BodhicAI. Effective Search Engine Optimization (SEO) ensures your skill ranks highly both on external search engines like Google and within BodhicAI's internal semantic search engine.

## 1. Crafting SEO-Optimized Skill Titles

Your title should balance clarity, keyword relevance, and professional appeal. Avoid vague names or overly technical jargon that buyers might not search for.

### Title Formula:
**[Primary Action/Domain] + [Target Tool/Framework] + [Value Proposition]**

```markdown
# WEAK TITLES
- Code Helper V2
- SEO Bot
- React Debugger

# HIGH-CONVERTING SEO TITLES
- Full-Stack Next.js 14 Performance & Core Web Vitals Optimizer
- Enterprise Postgres SQL Query Analyzer & Indexing Assistant
- Automated SaaS Copywriter & Conversion Rate Optimizer
```

## 2. Writing Meta-Descriptions for Search Snippets

The first 150 characters of your skill description serve as your meta description for search engine result pages (SERPs). Make this first paragraph punchy, keyword-rich, and focused on user benefits.

```markdown
# EXAMPLE META DESCRIPTION
Accelerate your Next.js development with an automated AI agent skill that analyzes React Server Components, diagnoses memory leaks, and optimizes Tailwind CSS bundles for maximum Lighthouse performance scores.
```

## 3. Selecting High-Impact Keywords & Categories

Tag your skill with relevant categories that match buyer search intent. Think about the exact phrases an engineering manager or developer would type into a search bar.

- **Primary Keywords**: Core technology stack (e.g., *Python, Docker, Kubernetes, Next.js, PyTorch*).
- **Secondary Keywords**: Task intent (e.g., *refactoring, unit testing, vulnerability scanning, code review*).
- **Long-Tail Keywords**: Specific problem solving (e.g., *fix React useEffect race condition, automate AWS CDK deployment*).

## 4. Structured Content for Semantic Search

BodhicAI uses advanced vector embeddings and semantic search to match user queries with skills. To rank higher in semantic search:
- Clearly list **Supported Frameworks & IDEs** (Cursor, Windsurf, Claude Desktop, VS Code).
- Provide explicit **Use Case Scenarios** with problem-solution pairings.
- Outline the **MCP Tools Included** within your skill bundle so automated agent discoverability algorithms can identify your skill's capabilities.

## 5. Building Authority & Social Proof

Search algorithms prioritize skills with high engagement. Boost your SEO authority by:
- Embedding visual walkthroughs and demonstration videos in your skill listing.
- Sharing your unique affiliate referral code on GitHub READMEs, developer blogs, and technical forums.
- Encouraging satisfied buyers to leave verified 5-star ratings and detailed reviews.
